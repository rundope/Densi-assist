# Densi-assist 사용자 매뉴얼

[English](USER_MANUAL.en.md) · **한국어** · [日本語](USER_MANUAL.ja.md) · [简体中文](USER_MANUAL.zh-CN.md)

겔·웨스턴 블롯 사진에서 밴드의 진하기(intensity)를 숫자로 재는 프로그램입니다.
웹 브라우저에서 동작하며, **이미지는 어떤 서버로도 전송되지 않고 내 컴퓨터 안에서만 처리됩니다.**
홈페이지 주소로 접속하거나, 설치 없이 **`Densi-assist.html` 파일을 더블클릭**해서 쓸 수 있습니다.

- 버전: 0.3
- 권장 브라우저: Chrome, Edge (최신 버전)

## 1. 한눈에 보는 작업 순서

```
이미지 올리기 → ① 선택 → ② 레인 → ③ 밴드 → 결과
```

| 단계 | 하는 일 | 필수 |
|---|---|---|
| 이미지 올리기 | 겔 사진을 끌어다 놓기 (여러 장 가능) | ✔ |
| ① 선택 | 밴드 색(어두운/밝은)과 화면 밝기 확인 | ✔ (대부분 자동) |
| ② 레인 | 레인을 그리거나 **레인 검출 (Auto)** | ✔ |
| ③ 밴드 | 밴드를 그리거나 **밴드 검출 (Auto)**, 기울기 조절 | ✔ |
| 베이스라인 | 밴드 밑 바닥선 방법 고르기 | 기본값(Rolling ball)으로 충분 |
| 결과 | 면적·% 확인, 엑셀로 내보내기 | ✔ |

가장 빠른 방법: **이미지 올리기 → ② 레인 → 레인 검출 (Auto) → ③ 밴드 → 밴드 검출 (Auto) → 결과 탭**

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────────────────┐
│ Densi-assist  [프로젝트 이름]   [분석] [결과]          ↶ ↷  [프로젝트 ▾] ? │
├───────────┬───────────────────────────────────────────┬──────────────────┤
│ 이미지 목록 │ [▢][▦]  (1 선택) › (2 레인) › (3 밴드)     │ 오른쪽 설정 패널   │
│           │ ─────────────────────────────────────────── │  1. 선택          │
│ [썸네일]   │                          [원본 이미지 보기] │   ① 이미지        │
│ 이름       │            겔 이미지 + 레인·밴드            │  2. 레인          │
│ 7 레인     │                                            │   ② 배경 제거     │
│ 21 밴드    │                            [－][＋][⤢][1:1] │   ③ 레인          │
│           │ ─────────────────────────────────────────── │  3. 밴드          │
│ [+ 추가]   │ 레인 프로파일 그래프 (선택한 레인)           │   ④ 베이스라인    │
│           │                                            │   ⑤ 밴드 · 타깃   │
└───────────┴───────────────────────────────────────────┴──────────────────┘
```

| 영역 | 설명 |
|---|---|
| **위쪽 탭** | **분석**(측정 작업), **결과**(표·그래프·내보내기) |
| **왼쪽 이미지 목록** | 올린 이미지들. 누르면 그 이미지로 이동. 이름을 두 번 누르면 이름 바꾸기 |
| **단계 버튼** | ① 선택 › ② 레인 › ③ 밴드. 지금 단계는 파란색으로 표시되고, 오른쪽 패널에서 그 단계 항목만 펼쳐짐 |
| **이미지 화면** | 레인(자홍색, 선택하면 파란색)과 밴드(주황색)가 겹쳐 보임 |
| **원본 이미지 보기** | 이미지 오른쪽 위. 켜면 레인·밴드 표시가 사라져 원본과 비교 가능 (키보드 **O**) |
| **확대/축소 버튼** | 이미지 오른쪽 아래: 축소, 확대, 화면에 맞춤, 1:1 원본 크기 |
| **프로파일 그래프** | 선택한 레인을 위→아래로 따라가며 잰 진하기. 봉우리 하나가 밴드 하나 |
| **오른쪽 설정 패널** | 제목을 누르면 펼쳐지고 접힘. 처음에는 모두 접혀 있음 |
| **↶ ↷** | 실행 취소 / 다시 실행 (Ctrl+Z / Ctrl+Shift+Z) |
| **프로젝트 ▾** | 이미지 추가, 새 프로젝트, 저장·불러오기, 데모 |

> 처음이라면 **프로젝트 ▾ → 데모 프로젝트 만들기**로 예제 이미지 3장이 들어 있는 프로젝트를 열어 둘러볼 수 있습니다.

## 3. 이미지 올리기

**방법 1.** 첫 화면의 점선 상자에 파일을 끌어다 놓거나, 상자를 눌러 파일을 고릅니다.
**방법 2.** 작업 중에는 왼쪽 목록의 **+ 추가** 버튼을 누르거나, 창 아무 곳에나 파일을 끌어다 놓습니다.
**방법 3.** 복사한 이미지(화면 캡처, 다른 프로그램에서 복사, 탐색기에서 복사한 이미지 파일)를 앱 화면에서 **Ctrl+V**로 붙여넣습니다. 캡처 이미지는 보통 8-bit라, 정량에는 원본 TIFF를 쓰는 편이 정확합니다.

- 여러 장을 한 번에 올릴 수 있습니다.
- 지원 형식: **TIFF** (8/16/32-bit, 여러 페이지), **PNG** (16-bit 포함), **JPG**, BMP

| 형식 | 권장 여부 |
|---|---|
| 이미저 원본 **16-bit TIFF** | ◎ 가장 권장. 흐린 밴드와 진한 밴드를 모두 정확히 잴 수 있음 |
| 8-bit TIFF / PNG | ○ 사용 가능 |
| JPG | △ 압축으로 픽셀 값이 바뀌어 있어 정량에는 권장하지 않음 (경고가 뜸) |

> 레인은 **세로 방향**이어야 합니다. 가로로 찍힌 이미지는 올리기 전에 회전해 주세요.

## 4. ① 선택 — 이미지 확인

위쪽 **① 선택**을 누르면 오른쪽에 **① 이미지** 설정이 펼쳐집니다.

### 밴드 색

| 선택지 | 언제 |
|---|---|
| 밝은 배경에 어두운 밴드 | 쿠마시·은염색, 대부분의 화학발광 이미지 (**기본, 자동 추천**) |
| 어두운 배경에 밝은 밴드 | 형광 이미지 |
| 어두운 밴드, 광학 밀도(OD)로 변환 | 필름 스캔, 투과광 스캔 |

올리는 순간 자동으로 추천되므로 대부분 그대로 두면 됩니다.

### 화면 밝기

- **표시 범위 그래프**: 두 세로선을 좌우로 끌어 화면의 밝기·대비를 조절합니다.
- **감마**: 흐린 밴드가 잘 보이도록 계조를 조절합니다.
- **자동 대비 / 초기화** 버튼.
- **배경 제거된 이미지로 보기**: ② 배경 제거 결과를 화면에서 확인할 때 사용합니다.

> **밝기·감마를 바꿔도 측정값은 바뀌지 않습니다.** 화면에만 적용되고, 계산은 항상 원본 픽셀 값으로 하기 때문입니다.
> 감마를 계산에 넣으면 밴드끼리의 비율이 실제 양의 비율과 달라지기 때문에 이렇게 분리했습니다.
> 꼭 필요하면 **"밝기·감마를 측정값에도 적용"** 을 켤 수 있으며, 이때는 결과와 엑셀에 표시가 남습니다.

### 이미지 기울기 보정

사진 전체가 약간 기울어졌을 때 −10°~+10° 범위에서 돌립니다.

## 5. ② 레인 — 레인 정하기

위쪽 **② 레인**을 누르면 옆에 두 가지가 나타납니다.

| 버튼 | 동작 |
|---|---|
| **레인 그리기** | 이미지의 빈 곳을 드래그해 레인을 그립니다. 그냥 한 번 클릭하면 선택된 레인과 같은 크기의 레인이 그 자리에 추가됩니다 |
| **레인 검출 (Auto)** | 레인을 자동으로 찾습니다. 붙어 있는 레인과 사이즈 마커(ladder) 레인도 찾습니다 |

### 레인 옮기기와 크기 바꾸기

도구를 바꿀 필요 없이 바로 할 수 있습니다.

- **옮기기**: 레인 안쪽을 끌어서 옮깁니다. **Shift**를 누른 채 끌면 가로로만 움직입니다.
- **크기**: 레인의 위·아래·왼쪽·오른쪽 테두리에 마우스를 올리면 화살표가 바뀝니다. 그때 끌면 그 테두리만 움직입니다.
- **삭제**: 레인을 고르고 **Delete** 키, 또는 오른쪽 ③ 레인 표의 휴지통.
- **레인 넘기기**: 키보드 **← →**.

### ③ 레인 설정 (오른쪽 패널)

| 항목 | 설명 |
|---|---|
| 레인 폭 | 슬라이더로 폭 조절 |
| 모든 레인 크기를 같게 | 켜 두면 한 레인의 폭·높이를 바꿀 때 모든 레인이 같이 바뀜 (권장) |
| 양옆 가장자리 제외 | 레인 양옆 몇 %를 빼고 가운데만 잽니다. 밴드 양끝이 번졌거나 휘었을 때 유용 (이미지에서 점선으로 표시) |
| 레인 폭 방향 값 합치기 | **평균**: 가로 한 줄 픽셀의 평균 (일반적) / **중앙값**: 먼지·반점처럼 튀는 픽셀에 덜 흔들림 |
| 샘플 이름 | 표에 직접 입력하거나, **엑셀에서 붙여넣기**로 한 열을 통째로 붙여 넣음 (왼쪽 레인부터 차례로) |
| 제외 | 체크한 레인은 결과에서 빠짐 |

> **샘플 이름이 중요합니다.** 결과 탭에서 **같은 이름의 레인끼리 묶여** 평균·표준편차가 계산됩니다. 이미지가 달라도 이름이 같으면 함께 묶입니다.

### ② 배경 제거 (선택 사항)

이미지 **전체**에 얼룩이나 그늘이 심할 때만 사용합니다. 보통은 **사용 안 함**으로 두고 베이스라인만 써도 충분합니다.

- Rolling ball / Paraboloid 중 선택
- 반경: 가장 두꺼운 밴드보다 크게
- 잡티 무시: 작은 먼지·노이즈를 먼저 고릅니다

## 6. ③ 밴드 — 밴드 정하기

위쪽 **③ 밴드**를 누르면 옆에 두 가지가 나타납니다.

| 버튼 | 동작 |
|---|---|
| **밴드 그리기** | 이미지: 레인 안에서 **위아래로** 드래그 / 아래 그래프: **좌우로** 드래그 |
| **밴드 검출 (Auto)** | 모든 레인의 밴드를 자동으로 찾습니다 |

### 밴드 다듬기

| 하고 싶은 것 | 방법 |
|---|---|
| 밴드 옮기기 | 이미지에서 밴드를 끌어 위아래로 이동 |
| 밴드 범위 바꾸기 | 밴드의 위·아래 테두리를 끌기 (이미지), 또는 그래프의 세로선을 좌우로 끌기 |
| **밴드 기울기** | 밴드를 고르면 양 끝 위쪽에 **동그라미 두 개**가 생깁니다. 왼쪽이나 오른쪽 동그라미를 위아래로 끌면 밴드가 비스듬해집니다 |
| 기울기 숫자로 입력 | 오른쪽 ⑤ 밴드 · 타깃 표의 **기울기** 칸 (왼쪽 끝과 오른쪽 끝의 높이 차, px) |
| 밴드 삭제 | 밴드를 고르고 **Delete** 키 |

> **기울기는 밴드마다 따로** 정합니다. SDS-PAGE에서 밴드가 비스듬히 내려갔을 때, 기울기를 맞추면 그 방향을 따라 다시 재기 때문에 봉우리가 번지지 않고 정확해집니다. 기울기를 바꾸면 아래 그래프의 검은 선도 그에 맞게 바뀝니다.

### 아래 프로파일 그래프 읽는 법

```
 진하기
   │        ╭╮
   │   ╭╮   ││        ← 검은 선: 레인의 진하기
   │  ╱  ╲ ╱  ╲
   │─○────○────○───   ← 주황 점선: 바닥선(베이스라인), ○: 밴드 시작·끝점
   └──────────────── 레인 위 → 아래
        밴드1  밴드2      주황색으로 칠한 넓이 = 밴드 면적
```

- 그래프 위쪽 이미지 띠는 선택한 레인을 눕혀 놓은 것이라, 그래프와 위치가 맞습니다.
- 봉우리 위에 밴드 번호와 **% (그 레인 안에서 차지하는 비율)** 가 표시됩니다.
- 마우스를 올리면 오른쪽 위에 위치·프로파일·베이스라인·신호 값이 나옵니다.
- **전체 레인 비교**: 모든 레인의 그래프를 작게 나란히 보여 줍니다. 바닥선이 레인마다 비슷하게 잡혔는지 확인할 때 좋습니다.

### ⑤ 밴드 · 타깃 (오른쪽 패널)

- 선택한 레인의 밴드 표: **#**, **기울기**, **면적**, **% 레인**
- **표 복사**: 이 레인의 표를 복사 → 엑셀에 붙여넣기
- **겔 전체 복사**: 이 이미지의 모든 레인 밴드를 한 번에 복사
- **구간 → 모든 레인**: 지금 레인의 밴드 구간을 모든 레인에 똑같이 복사
- **타깃(단백질 이름)**: **+ 타깃**으로 이름을 만들고, 밴드를 고른 뒤 타깃을 누르면 **같은 높이의 밴드에 한 번에** 지정됩니다. 타깃 이름은 두 번 눌러 바꿉니다. 결과 탭의 샘플별 요약에 쓰입니다.
- **자동 검출 민감도**: 흐린 밴드까지 찾을지, 밴드 끝을 어디로 볼지 조절합니다.

## 7. 베이스라인 — 바닥선 정하기

**베이스라인**은 그래프에서 밴드 밑의 **바닥선**입니다. 바닥선 위의 넓이가 밴드 값(면적)이 됩니다.

> **배경 제거 vs 베이스라인**
> - ② 배경 제거: 이미지 **전체**의 얼룩·그늘을 지웁니다 (선택 사항).
> - ④ 베이스라인: **레인마다** 그래프에서 바닥선을 정합니다 (항상 사용).

오른쪽 **④ 베이스라인**을 펼쳐 방법을 고릅니다.

| 방법 | 설명 | 언제 |
|---|---|---|
| **Rolling ball** (기본) | 그래프 아래에서 공을 굴려 닿는 궤적을 바닥선으로 | 대부분의 경우 |
| Top-hat | 평평한 막대로 봉우리를 깎아냄 | 배경이 거의 평평할 때 |
| Rubber band | 그래프 아래에 고무줄을 걸친 모양 | 밴드가 적당히 떨어져 있을 때 |
| SNIP | 창을 넓혀 가며 봉우리를 깎아냄 | 밴드가 많고 폭이 제각각일 때 |
| 이동 중앙값 | 넓은 구간의 중앙값 | 밴드가 드문드문하고 노이즈가 많을 때 |
| **수동 (밴드 시작·끝점)** | 밴드마다 시작점과 끝점을 직선으로 이음 | 바닥선을 직접 정하고 싶을 때 |
| 없음 | 바닥선 0 | 배경 제거를 이미 충분히 했을 때 |

각 방법을 고르면 **"이럴 때"** 와 **"주의"** 설명이 함께 나옵니다.

### Rolling ball의 "공 크기"

공이 작으면 밴드 봉우리 속까지 들어가 **밴드를 깎아 먹고**, 너무 크면 **배경이 덜 빠집니다.**
**가장 넓은 밴드보다 크게** 잡으세요. 레인 길이에 대한 %로 정하며, 옆에 실제 px 값이 함께 표시됩니다.

### 수동 바닥선 그리기

1. 방법에서 **수동 (밴드 시작·끝점)** 을 고르거나, 그래프 위 **수동으로 다듬기** 버튼을 누릅니다.
   - "수동으로 다듬기"는 지금의 자동 바닥선을 출발점으로 삼아 그 레인만 수동으로 바꿉니다.
2. 그래프에서 각 밴드 양 끝의 **동그라미**가 커집니다.
3. 동그라미를 끌면:
   - **가로** → 밴드 시작·끝 위치
   - **세로** → 그 점의 바닥 높이
4. 동그라미를 **오른쪽 클릭**하면 그 점의 높이가 자동(그 위치의 골짜기 값)으로 돌아갑니다.

> 수동 바닥선은 두 점을 **직선**으로 잇습니다. Rolling ball(곡선)에서 바꾸면 면적이 조금 달라질 수 있습니다.

### 적용할 곳

- **이 겔 전체**: 이 이미지의 모든 레인에 같은 방법
- **선택한 레인만**: 특정 레인만 다르게
- **모든 겔에 같은 설정**: 프로젝트의 모든 이미지에 적용 (결과를 일관되게 만들 때)

### 바닥선이 그래프보다 높은 곳

- **0으로 계산 (권장)**: 음수 부분은 0으로 칩니다
- **빼서 계산**: 음수도 그대로 더합니다

## 8. 결과 보기와 엑셀로 내보내기

위쪽 **결과** 탭을 누릅니다.

### 전체 밴드

모든 이미지의 밴드가 한 표에 나옵니다: 이미지, 레인, 샘플, 밴드, 타깃, 기울기, **면적**, **% 레인**

- 열 제목을 누르면 정렬됩니다.
- 행을 누르면 분석 화면의 그 밴드로 이동합니다.
- 포화된 밴드에는 **포화** 표시가 붙습니다 (값이 실제보다 작게 나올 수 있음).

| 버튼 | 결과 |
|---|---|
| **엑셀** | `.xlsx` 파일. 시트: 샘플별 요약(있을 때), 밴드(위치·Rf·높이·Volume 포함), **설정**(파일 정보와 모든 분석 설정 — 나중에 같은 결과를 다시 얻기 위한 기록) |
| **CSV** | 한글이 깨지지 않는 CSV |
| **표 복사** | 클립보드로 복사 → 엑셀에 바로 붙여넣기 |

### 샘플별 요약 (타깃을 지정했을 때)

- 같은 샘플 이름의 레인을 모아 **평균 ± 표준편차 (n = 레인 수)**
- **기준 샘플**을 고르면 기준 = 1로 한 **상대값(×)** 이 함께 나옵니다 (예: Control 대비 몇 배)
- 막대 그래프: 막대 = 평균, 점 = 각 레인 값, 선 = 표준편차

### 면적과 % 레인

| 값 | 의미 |
|---|---|
| **면적** | 바닥선 위의 넓이. 레인 폭 방향 평균값을 위→아래로 더한 값 |
| **% 레인** | 그 레인의 모든 밴드 면적 합에 대한 비율 |
| Volume (엑셀) | 면적 × 사용한 레인 폭(px). 적분 밀도에 해당 |

## 9. 여러 장의 이미지를 한 번에 다루기

한 실험에서 나온 여러 장의 겔을 **한 프로젝트**에서 함께 분석할 수 있습니다.

1. 이미지를 모두 올립니다.
2. 위쪽 **▦ (전체 보기)** 를 누르면 모든 이미지가 레인·밴드와 함께 한 화면에 나옵니다.
3. **모든 겔 자동 분석**으로 레인과 밴드를 한 번에 잡습니다.
4. 이미지마다 레인 위치와 **샘플 이름**을 확인합니다. 같은 샘플은 **이름을 똑같이** 적으세요.
5. 한 이미지에서 정한 처리 설정은 ⑤ 밴드 · 타깃 맨 아래 **"이 겔의 처리 설정을 모든 겔에 복사"** 로 통일합니다.
6. 같은 배치로 로딩한 겔이면 ③ 레인의 **"레인 배치를 다른 겔로 복사"** 로 레인 위치와 샘플 이름을 복사합니다.
7. 결과 탭에서 모든 이미지의 값을 함께 보고 내보냅니다.

## 12. 좋은 결과를 얻기 위한 팁

1. **원본 16-bit TIFF를 쓰세요.** JPG나 화면 캡처는 값이 바뀌어 있습니다.
2. **포화를 피하세요.** 포화된 밴드는 윗부분이 잘려 실제보다 작게 측정됩니다. "포화" 표시가 보이면 노출 시간을 줄여 다시 찍는 것이 좋습니다.
3. **모든 레인을 같은 폭으로.** "모든 레인 크기를 같게"를 켜 두세요.
4. **베이스라인은 한 가지로 통일.** 비교할 이미지들은 "모든 겔에 같은 설정"으로 같은 방법을 쓰세요.
5. **공 크기는 넉넉하게.** Rolling ball 공 크기가 밴드보다 작으면 밴드가 깎입니다. "전체 레인 비교"로 바닥선이 밴드 밑을 지나는지 확인하세요.
6. **기울어진 밴드는 기울기를 맞추세요.** 봉우리가 뾰족해지는 방향이 맞는 기울기입니다.
7. **원본 이미지 보기(O)** 로 레인·밴드를 숨기고 원본과 번갈아 보며 위치를 확인하세요.
8. **샘플 이름을 정확히.** 같은 샘플은 같은 이름이어야 결과에서 묶입니다.

## 13. 자주 묻는 질문

**Q. 설치 없이 바로 쓸 수 있나요?**
A. 네. 프로그램 폴더의 **`Densi-assist.html`** (또는 `index.html`)을 더블클릭하면 Chrome·Edge에서 바로 실행됩니다. 프로그램 전체가 이 파일 하나에 들어 있어 이 파일만 복사해서 써도 됩니다.
파일로 열어 쓸 때도 작업은 브라우저에 자동 저장되지만, 중요한 작업은 **프로젝트 ▾ → 프로젝트 파일로 저장**으로 `.densi` 파일을 남겨 두세요.

**Q. 파일을 열었는데 "이미지 처리 모듈을 불러오지 못했습니다"라고 나와요.**
A. 브라우저가 파일로 연 페이지의 일부 기능을 막은 경우입니다. Chrome이나 Edge 최신 버전으로 열거나, 회사 홈페이지 주소로 접속하세요.

**Q. 감마를 바꿨는데 측정값이 그대로예요.**
A. 정상입니다. 감마·밝기는 화면에만 적용됩니다. [4장](#4--선택--이미지-확인)을 참고하세요.

**Q. 레인 검출 (Auto)이 레인을 잘못 찾아요.**
A. ① 이미지의 **밴드 색** 설정이 맞는지 먼저 확인하세요. 그래도 어긋나면 레인을 끌어 옮기거나 직접 그리면 됩니다. 레인 사이 간격이 거의 없는 겔은 **레인 그리기**로 하나 그린 뒤, 옆 위치를 **한 번씩 클릭**하면 같은 크기로 빠르게 추가됩니다.

**Q. 밴드가 너무 많이(또는 적게) 잡혀요.**
A. ⑤ 밴드 · 타깃의 **자동 검출 민감도 → 작은 밴드도 찾기** 값을 올리면(덜 찾음) 또는 내리면(더 찾음) 됩니다. 필요 없는 밴드는 고르고 **Delete**.

**Q. 면적 값의 단위는 무엇인가요?**
A. 상대 단위입니다. 이미지·노출 조건에 따라 달라지므로, 같은 이미지 안에서의 비교나 기준 샘플 대비 상대값으로 해석하세요.

**Q. 이미지가 서버로 올라가나요?**
A. 아니요. 모든 처리는 내 컴퓨터의 브라우저 안에서 이루어집니다. 프로그램 파일만 내려받아 실행됩니다.

**Q. 실수로 지웠어요.**
A. **Ctrl+Z**(또는 위쪽 ↶)로 되돌릴 수 있습니다. 삭제 직후에는 알림창의 **되돌리기** 버튼도 쓸 수 있습니다.

## 14. 용어 설명

| 용어 | 뜻 |
|---|---|
| 레인 (lane) | 시료 하나가 내려간 세로 줄 |
| 밴드 (band) | 레인 안에서 단백질/DNA가 모여 진하게 보이는 가로 띠 |
| 프로파일 (profile) | 레인을 위→아래로 따라가며 잰 진하기 곡선 |
| 베이스라인 (baseline) | 프로파일에서 밴드 밑의 바닥선. 이 위의 넓이가 밴드 값 |
| 면적 (area) | 바닥선 위 봉우리의 넓이 |
| % 레인 | 한 레인 안 모든 밴드 면적의 합에 대한 비율 |
| 포화 (saturation) | 너무 진해서 카메라가 잴 수 있는 최댓값에 닿은 상태. 실제보다 작게 측정됨 |
| 타깃 (target) | 밴드에 붙이는 단백질 이름. 결과를 모아 볼 때 사용 |
| 기준 샘플 | 상대값을 계산할 때 1로 두는 샘플 (예: Control) |
| 사이즈 마커 (ladder) | 분자량을 알 수 있는 표준 밴드들이 있는 레인 |
