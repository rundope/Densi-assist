# Densi-assist 用户手册

[English](USER_MANUAL.en.md) · [한국어](USER_MANUAL.ko.md) · [日本語](USER_MANUAL.ja.md) · **简体中文**

Densi-assist 是一款将凝胶和蛋白质印迹（Western blot）图像中条带的灰度（intensity）转换为数值的程序。
它在网页浏览器中运行，**图像不会发送到任何服务器，全部在您自己的电脑上处理。**
您可以通过网址打开，也可以无需安装，直接**双击 `Densi-assist.html` 文件**使用。

- 版本：0.3
- 推荐浏览器：Chrome、Edge（最新版本）

> **关于界面语言**
> 本程序的界面为韩语。本手册中的界面文字**按界面上的韩语原样书写**，并在其后的括号中附上中文翻译，例如 **분석**（分析）。请在界面上查找对应的韩语文字。

## 1. 操作流程一览

```
添加图像 → ① 选择 → ② 泳道 → ③ 条带 → 结果
```

| 步骤 | 操作内容 | 必需 |
|---|---|---|
| 添加图像 | 拖放凝胶图像（可同时添加多张） | ✔ |
| ① **선택**（选择） | 确认条带颜色（深色/浅色）和显示亮度 | ✔（基本自动） |
| ② **레인**（泳道） | 绘制泳道，或使用 **레인 검출 (Auto)**（检测泳道） | ✔ |
| ③ **밴드**（条带） | 绘制条带，或使用 **밴드 검출 (Auto)**（检测条带），调整倾斜 | ✔ |
| 基线 | 选择条带下方底线的计算方法 | 默认值（Rolling ball）通常即可 |
| **결과**（结果） | 查看面积和 %，导出到 Excel | ✔ |

最快的方法：**添加图像 → ② 레인 → 레인 검출 (Auto) → ③ 밴드 → 밴드 검출 (Auto) → 결과 选项卡**

## 3. 添加图像

**方法 1.** 在开始界面将文件拖放到虚线框中，或单击虚线框选择文件。
**方法 2.** 操作过程中，单击图像列表上方的 **+ 추가**（添加），或将文件拖放到窗口任意位置。
**方法 3.** 在应用窗口中用 **Ctrl+V** 粘贴已复制的图像（屏幕截图、从其他程序复制、在资源管理器中复制的图像文件）。截图通常是 8-bit，定量时使用原始 TIFF 更准确。

- 可以一次添加多张图像。
- 支持的格式：**TIFF**（8/16/32 位，多页）、**PNG**（含 16 位）、**JPG**、BMP

| 格式 | 推荐程度 |
|---|---|
| 成像仪原始 **16 位 TIFF** | ◎ 最推荐。浅条带和深条带都能准确测量 |
| 8 位 TIFF / PNG | ○ 可以使用 |
| JPG | △ 压缩会改变像素值，不推荐用于定量（会显示警告） |

> 泳道必须是**竖直方向**。横向拍摄的图像请在添加前先旋转。

## 4. ① 选择 — 检查图像

单击顶部的 **① 선택**（选择），右侧会展开 **① 이미지**（图像）设置。

### 条带颜色

| 界面选项 | 适用情况 |
|---|---|
| **밝은 배경에 어두운 밴드**（浅色背景上的深色条带） | 考马斯亮蓝/银染、大多数化学发光图像（**默认，自动推荐**） |
| **어두운 배경에 밝은 밴드**（深色背景上的浅色条带） | 荧光图像 |
| **어두운 밴드，광학 밀도（OD）로 변환**（深色条带，转换为光密度 OD） | 胶片扫描、透射光扫描 |

添加图像时会自动推荐合适的选项，大多数情况下保持不变即可。

### 显示亮度

- **显示范围图**：左右拖动两条竖线，调整屏幕显示的亮度和对比度。
- **감마**（伽马）：调整灰阶，使浅条带更容易看清。
- **자동 대비**（自动对比度） / **초기화**（重置）按钮。
- **배경 제거된 이미지로 보기**（显示去除背景后的图像）：用于在屏幕上查看 ② 背景去除的结果。

> **更改亮度或伽马不会改变测量值。** 它们只作用于屏幕显示，计算始终使用原始像素值。
> 之所以分开，是因为如果把伽马纳入计算，条带之间的比例就会与实际含量的比例不同。
> 如确有需要，可以开启 **밝기·감마를 측정값에도 적용**（将亮度·伽马也应用于测量值），此时结果和 Excel 中会留有标记。

### 图像倾斜校正

整张图像略有倾斜时，可在 −10°~+10° 范围内旋转（**기울기 보정**，倾斜校正）。

## 5. ② 泳道 — 设置泳道

单击顶部的 **② 레인**（泳道），旁边会出现两个按钮。

| 按钮 | 作用 |
|---|---|
| **레인 그리기**（绘制泳道） | 在图像空白处拖动即可绘制泳道。单击一次，会在该位置添加一条与所选泳道大小相同的泳道 |
| **레인 검출 (Auto)**（检测泳道） | 自动查找泳道，包括相互紧贴的泳道和分子量标准（Marker/Ladder）泳道 |

### 移动泳道和调整大小

无需切换工具即可直接操作。

- **移动**：拖动泳道内部。按住 **Shift** 拖动时只能水平移动。
- **大小**：将鼠标移到泳道的上、下、左、右边框上，光标会变成箭头，此时拖动只会移动该边框。
- **删除**：选中泳道后按 **Delete** 键，或点击右侧 ③ 泳道表中的垃圾桶图标。
- **切换泳道**：**← →** 键。

### ③ 레인（泳道）设置（右侧面板）

| 界面项目 | 说明 |
|---|---|
| **레인 폭**（泳道宽度） | 用滑块调整宽度 |
| **모든 레인 크기를 같게**（所有泳道大小相同） | 开启后，更改一条泳道的宽度或高度时，所有泳道一起改变（推荐） |
| **양옆 가장자리 제외**（排除两侧边缘） | 去掉泳道两侧一定百分比，只测量中间部分。适用于条带两端弥散或弯曲的情况（在图像上以虚线显示） |
| **레인 폭 방향 값 합치기**（泳道宽度方向的数值合并方式） | **평균**（平均值）：每一行像素的平均值（常用） / **중앙값**（中位数）：不易受灰尘、斑点等异常像素影响 |
| **샘플 이름**（样品名称） | 直接在表格中输入，或用 **엑셀에서 붙여넣기**（从 Excel 粘贴）一次粘贴整列（从最左侧泳道开始依次填入） |
| **제외**（排除） | 勾选的泳道不计入结果 |

> **样品名称很重要。** 在结果选项卡中，**同名泳道会被归为一组**，并计算平均值和标准差。即使来自不同图像，名称相同也会归为一组。

### ② 배경 제거（背景去除，可选）

仅在**整张**图像有明显污渍或阴影时使用。通常保持 **사용 안 함**（不使用），只使用基线即可。

- 在 Rolling ball / Paraboloid 中选择
- **반경**（半径）：大于最宽的条带
- **잡티 무시**（忽略杂点）：先平滑掉小灰尘和噪点

## 6. ③ 条带 — 设置条带

单击顶部的 **③ 밴드**（条带），旁边会出现两个按钮。

| 按钮 | 作用 |
|---|---|
| **밴드 그리기**（绘制条带） | 在图像上：在泳道内**上下**拖动 / 在下方曲线图上：**左右**拖动 |
| **밴드 검출 (Auto)**（检测条带） | 自动查找所有泳道中的条带 |

### 调整条带

| 想要做的事 | 方法 |
|---|---|
| 移动条带 | 在图像上上下拖动条带 |
| 更改条带范围 | 拖动条带的上下边框（图像），或左右拖动曲线图中的竖线 |
| **条带倾斜** | 选中条带后，两端上方会出现**两个圆点**。上下拖动左侧或右侧的圆点，条带就会倾斜 |
| 用数字输入倾斜 | 右侧 ⑤ 条带·目标表中的 **기울기**（倾斜）列（左端与右端的高度差，单位 px） |
| 删除条带 | 选中条带后按 **Delete** 键 |

> **倾斜按条带分别设置。** 在 SDS-PAGE 中条带斜向迁移时，调好倾斜后会沿该方向重新测量，峰不会展宽，结果更准确。更改倾斜时，下方曲线图中的黑线也会随之改变。

### 如何阅读轮廓曲线图

```
 Intensity
   │        ╭╮
   │   ╭╮   ││        ← 黑线:泳道的灰度
   │  ╱  ╲ ╱  ╲
   │─○────○────○───   ← 橙色虚线:底线(基线),○:条带起点/终点
   └──────────────── 泳道上端 → 下端
        band 1  band 2    橙色填充的面积 = 条带面积
```

- 曲线图上方的图像条是将所选泳道横放后的样子，位置与曲线图一一对应。
- 每个峰上方显示条带编号和 **%（在该泳道中所占比例）**。
- 将鼠标悬停在图上，右上角会显示位置、轮廓、基线和信号值。
- **전체 레인 비교**（比较所有泳道）：将所有泳道的曲线图缩小并排显示，便于检查各泳道的底线是否一致。

### ⑤ 밴드 · 타깃（条带·目标，右侧面板）

- 所选泳道的条带表：**#**、**기울기**（倾斜）、**면적**（面积）、**% 레인**（泳道内 %）
- **표 복사**（复制表格）：复制该泳道的表格 → 粘贴到 Excel
- **겔 전체 복사**（复制整个凝胶）：一次复制该图像所有泳道的条带
- **구간 → 모든 레인**（范围 → 所有泳道）：将当前泳道的条带范围原样复制到所有泳道
- **타깃**（目标，蛋白名称）：用 **+ 타깃** 创建名称，选中条带后单击目标，即可**一次性**指定给**同一高度的所有条带**。双击目标名称可重命名。用于结果选项卡中的按样品汇总。
- **자동 검출 민감도**（自动检测灵敏度）：调整是否检测浅条带，以及条带边界的判定位置。

## 7. 基线 — 设置底线

**基线**是曲线图中条带下方的**底线**。底线以上的面积即为条带值（面积）。

> **背景去除与基线的区别**
> - ② 背景去除：去除**整张图像**的污渍和阴影（可选）。
> - ④ 基线：在曲线图上**逐条泳道**确定底线（始终使用）。

展开右侧的 **④ 베이스라인**（基线），选择 **방법**（方法）。

| 界面上的方法 | 说明 | 适用情况 |
|---|---|---|
| **Rolling ball / disk (1D)**（默认） | 从曲线下方滚动一个球，以其接触轨迹作为底线 | 大多数情况 |
| **Top-hat** | 用平直的结构元素削去峰 | 背景几乎平坦时 |
| **Rubber band** | 像在曲线下方张开一根橡皮筋 | 条带之间间隔适中时 |
| **SNIP** | 逐步加宽窗口削去峰 | 条带多且宽度不一时 |
| **이동 중앙값 + Gaussian**（滑动中位数） | 较宽区间内的中位数 | 条带稀疏且噪声多时 |
| **수동 （밴드 시작·끝점）**（手动：条带起点/终点） | 用直线连接每条条带的起点和终点 | 想自己确定底线时 |
| **없음**（无） | 底线为 0 | 已充分去除背景时 |

选择方法后，会同时显示 **이럴 때**（适用情况）和 **주의**（注意）说明。

### Rolling ball 的"球的大小"

球太小会伸入峰内部**削掉条带**，太大则**背景去除不足**。
请设置得**比最宽的条带更大**。以泳道长度的百分比设定，旁边会同时显示实际的 px 值。

### 手动绘制底线

1. 在方法中选择 **수동 （밴드 시작·끝점）**，或单击曲线图上方的 **수동으로 다듬기**（手动微调）按钮。
   - "手动微调"会以当前的自动底线为起点，只将该泳道切换为手动。
2. 曲线图中每条条带两端的**圆点**会变大。
3. 拖动圆点：
   - **水平** → 条带起点/终点的位置
   - **垂直** → 该点的底线高度
4. **右键单击**圆点，该点的高度会恢复为自动（该位置的谷值）。

> 手动底线用**直线**连接两点。从 Rolling ball（曲线）切换过来时，面积可能会略有变化。

### 应用范围

- **이 겔 전체**（整个凝胶）：该图像的所有泳道使用同一方法
- **선택한 레인만**（仅所选泳道）：仅对特定泳道使用不同方法
- **모든 겔에 같은 설정**（所有凝胶使用相同设置）：应用到项目中的所有图像（使结果保持一致）

### 底线高于曲线的部分

- **0으로 계산**（按 0 计算，推荐）：负值部分按 0 计
- **빼서 계산**（相减计算）：负值部分也直接累加

## 8. 查看结果与导出到 Excel

单击顶部的 **결과**（结果）选项卡。

### 全部条带

所有图像的条带显示在一个表中：**이미지**（图像）、**레인**（泳道）、**샘플**（样品）、**밴드**（条带）、**타깃**（目标）、**기울기**（倾斜）、**면적**（面积）、**% 레인**（泳道内 %）

- 单击列标题可排序。
- 单击某行会跳转到分析界面中的该条带。
- 饱和的条带会标记为 **포화**（饱和）（测得值可能小于实际值）。

| 按钮 | 结果 |
|---|---|
| **엑셀**（Excel） | `.xlsx` 文件。工作表：按样品汇总（如有）、条带（含位置、Rf、高度、Volume）、**设置**（文件信息和所有分析设置 — 用于日后重现相同结果的记录） |
| **CSV** | 韩文不会乱码的 CSV |
| **표 복사**（复制表格） | 复制到剪贴板 → 直接粘贴到 Excel |

### 按样品汇总（指定目标后）

- 将同名样品的泳道合并：**平均值 ± 标准差（n = 泳道数）**
- 选择 **기준 샘플**（参照样品）后，会同时显示以参照 = 1 的**相对值（×）**（例如相对于 Control 的倍数）
- 柱状图：柱 = 平均值，点 = 各泳道的值，线 = 标准差

### 面积与泳道内 %

| 数值 | 含义 |
|---|---|
| **면적**（面积） | 底线以上的面积。将泳道宽度方向的平均值从上到下累加所得 |
| **% 레인**（泳道内 %） | 占该泳道所有条带面积总和的比例 |
| Volume（Excel） | 面积 × 所用泳道宽度（px）。相当于积分灰度 |

## 9. 同时处理多张图像

同一实验得到的多块凝胶可以在**一个项目**中一起分析。

1. 添加所有图像。
2. 单击顶部的 **▦**（总览），所有图像会连同泳道和条带显示在同一界面上。
3. 用 **모든 겔 자동 분석**（自动分析所有凝胶）一次性检测泳道和条带。
4. 逐张检查泳道位置和**样品名称**。同一样品请使用**完全相同的名称**。
5. 在一张图像中确定的处理设置，可通过 ⑤ 条带·目标最下方的 **이 겔의 처리 설정을 모든 겔에 복사**（将此凝胶的处理设置复制到所有凝胶）统一。
6. 如果凝胶的上样布局相同，可用 ③ 泳道中的 **레인 배치를 다른 겔로 복사**（将泳道布局复制到其他凝胶）复制泳道位置和样品名称。
7. 在结果选项卡中一起查看并导出所有图像的数值。

## 12. 获得良好结果的技巧

1. **请使用原始 16 位 TIFF。** JPG 和屏幕截图的数值已被改变。
2. **避免饱和。** 饱和条带的顶部被截断，测得值会小于实际值。如果看到 **포화**（饱和）标记，建议缩短曝光时间重新拍摄。
3. **所有泳道使用相同宽度。** 请开启 **모든 레인 크기를 같게**。
4. **基线方法保持统一。** 需要比较的图像请通过 **모든 겔에 같은 설정** 使用相同方法。
5. **球要足够大。** Rolling ball 的球小于条带时，条带会被削掉。请用 **전체 레인 비교** 确认底线是否从条带下方通过。
6. **倾斜的条带要调好倾斜。** 使峰最尖锐的倾斜就是正确的倾斜。
7. 用**原始图像显示（O）**隐藏泳道和条带，与原图交替对照，确认位置。
8. **样品名称要准确。** 只有同名的样品才会在结果中归为一组。

## 13. 常见问题

**问：无需安装就能直接使用吗?**
答：可以。双击程序文件夹中的 **`Densi-assist.html`**（或 `index.html`），即可在 Chrome、Edge 中直接运行。整个程序都包含在这一个文件中，也可以只复制这个文件使用。
以文件方式打开时，工作内容同样会自动保存在浏览器中，但重要的工作请通过 **프로젝트 ▾ → 프로젝트 파일로 저장** 保存 `.densi` 文件。

**问：打开文件后显示"이미지 처리 모듈을 불러오지 못했습니다"（无法加载图像处理模块）。**
答：这是浏览器阻止了以文件方式打开的页面的部分功能。请使用最新版 Chrome 或 Edge 打开，或通过公司网站地址访问。

**问：更改了伽马，但测量值没有变化。**
答：这是正常的。伽马和亮度只作用于屏幕显示。请参阅[第 4 节](#4--选择--检查图像)。

**问：레인 검출 (Auto) 找错了泳道。**
答：请先确认 ① 图像中的**条带颜色**设置是否正确。如果仍有偏差，可以拖动泳道调整位置，或自己绘制。对于泳道之间几乎没有间隙的凝胶，先用 **레인 그리기** 绘制一条泳道，再在相邻位置**各单击一次**，即可快速添加相同大小的泳道。

**问：检测到的条带太多（或太少）。**
答：在 ⑤ 条带·目标中，调高 **자동 검출 민감도 → 작은 밴드도 찾기**（自动检测灵敏度 → 也查找小条带）的数值可减少检测数量，调低则增加。不需要的条带选中后按 **Delete**。

**问：面积值的单位是什么?**
答：是相对单位。它随图像和曝光条件而变化，请将其理解为同一图像内的比较，或相对于参照样品的相对值。

**问：图像会上传到服务器吗?**
答：不会。所有处理都在您电脑上的浏览器中进行。只会下载并运行程序文件。

**问：不小心删除了内容。**
答：按 **Ctrl+Z**（或顶部的 ↶）即可撤销。刚删除后，也可以使用通知中的 **되돌리기**（撤销）按钮。

## 14. 术语表

| 术语 | 含义 |
|---|---|
| 泳道（레인） | 一个样品迁移形成的纵向通道 |
| 条带（밴드） | 泳道中蛋白质/DNA 聚集而显得较深的横向带 |
| 轮廓曲线（프로파일） | 沿泳道从上到下测得的灰度曲线 |
| 基线（베이스라인） | 轮廓曲线中条带下方的底线。其上方的面积即为条带值 |
| 面积（면적） | 基线以上峰的面积 |
| 泳道内 %（% 레인） | 占一条泳道内所有条带面积总和的比例 |
| 饱和（포화） | 信号过强，达到相机可测量的最大值的状态。测得值小于实际值 |
| 目标（타깃） | 为条带指定的蛋白名称，用于汇总结果 |
| 参照样品（기준 샘플） | 计算相对值时设为 1 的样品（例如 Control） |
| 分子量标准 / Marker（사이즈 마커） | 含有已知分子量标准条带的泳道 |
