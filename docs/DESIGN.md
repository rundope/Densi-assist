# Densi-assist 설계 문서

전기영동/웨스턴 블롯 밴드의 intensity를 정량하는 웹 기반 densitometry 도구.
사전 조사 결과는 [RESEARCH.md](RESEARCH.md) 참고.

- 버전: v0.3 (2026-09-21). v0.3에서 화면 단순화, 밴드 기울기, 수동 바닥선(밴드 시작·끝점), 원본 이미지 보기를 추가하고, 표준곡선·로딩 컨트롤 정규화 화면은 숨겼다 (코드는 유지).
- 스택: React 19 + TypeScript + Vite, zustand + immer, geotiff, fast-png, fflate, SheetJS
- 처리 위치: 전부 브라우저 안 (Web Worker). 이미지는 서버로 전송되지 않음

---

## 1. 설계 원칙

1. **원본 픽셀 보존**: 원본 파일 바이트는 IndexedDB에 그대로 두고, 모든 처리는 사본에서 한다.
2. **표시와 정량 분리**: (v0.3 설계. 2026-11-27에 감마·부드럽게는 "측정에도 적용" 체크로 정량 반영하도록 바뀌었음 — HANDOFF.md 5장 참고) 밝기·대비·감마는 기본적으로 화면 LUT에만 적용하고, 정량은 원본 값(+ 선택한 극성/배경 처리)으로 계산한다. 원한다면 "감마·표시 범위를 정량에도 적용"을 켤 수 있으며, 이때는 비선형 변환이 적용되었다는 표시가 결과와 내보내기에 함께 남는다.
3. **모든 결정은 프로젝트에 기록**: 극성, 회전, 레인 좌표, 베이스라인 방법·파라미터·수동 점, 밴드 경계, 타깃 지정까지 저장한다. 같은 이미지 + 같은 프로젝트 = 같은 숫자.
4. **순수 함수 코어**: `src/core`는 React/DOM에 의존하지 않고 Vitest로 검증한다.
5. **방해하지 않는 부가 기능**: 여러 겔 요약, 표준곡선은 별도 탭에 둔다. 분석 화면은 측정에만 집중한다.
6. **경고는 적극적으로**: 포화 픽셀, JPG 손실 압축, 8-bit, 음수 신호, 표준곡선 외삽을 표시한다.

## 2. 화면 구성

```
┌ 헤더: 프로젝트 이름 │ [분석] [결과] [표준곡선] │ 저장 상태 · 실행취소 · 프로젝트 메뉴 · 도움말 ┐
├──────────┬───────────────────────────────────────────┬────────────────────┤
│ 겔 목록  │ 도구막대: 한 장/전체 보기, 선택·레인·밴드  │ 인스펙터 (단계)    │
│ (썸네일, │ ───────────────────────────────────────── │ ① 이미지           │
│ 레인·밴드│ 이미지 뷰포트 (줌/팬, 레인·밴드 오버레이)  │ ② 배경 제거 (2D)   │
│ 수 배지) │ ───────────────────────────────────────── │ ③ 레인             │
│          │ 프로파일 패널 (레인 스트립 + 그래프,       │ ④ 베이스라인       │
│          │  또는 전체 레인 비교)                      │ ⑤ 밴드 · 타깃      │
└──────────┴───────────────────────────────────────────┴────────────────────┘
```

- **전체 보기(그리드)**: 프로젝트의 모든 겔을 레인·밴드 오버레이와 함께 한눈에 보여준다. "모든 겔 자동 분석" 버튼과 다중 겔 작업 순서 안내가 있다.
- **이미지 ↔ 그래프 동기화**: 밴드 경계는 이미지(가로선)와 그래프(세로선) 어느 쪽에서 드래그해도 같은 데이터를 바꾼다.
- **전체 레인 비교**: 모든 레인의 프로파일과 베이스라인을 작은 그래프로 나란히 보여줘, 베이스라인이 일관되게 잡혔는지 확인한다.

## 3. 여러 겔을 한 창에서 다루는 방식

| 개념 | 역할 |
|---|---|
| **프로젝트** | 여러 겔 + 타깃 목록 + 표준곡선 + 정규화 설정 |
| **샘플 이름** (레인) | 겔을 넘는 연결 키. 같은 이름의 레인은 결과 표에서 한 샘플의 반복으로 묶인다 |
| **타깃** (밴드) | 단백질 이름. ★ 표시는 로딩 컨트롤 |
| **처리 설정 복사** | 한 겔의 극성·배경·프로파일·베이스라인·검출 설정을 모든 겔에 적용 (회전은 겔마다 유지) |
| **레인 배치 복사** | 같은 배치로 로딩한 다른 겔에 레인 좌표·샘플 이름 복사 (이미지 크기 비율로 환산) |
| **모든 겔 자동 분석** | 레인이 없는 겔은 레인 검출, 밴드가 없는 레인은 밴드 검출 |

### 정규화 (결과 탭)
- 레인 안에서 같은 타깃 밴드가 여러 개면 합산한다 (이중 밴드).
- **L (같은 레인)**: 대상 샘플의 모든 레인에 로딩 컨트롤 밴드가 있으면 레인마다 `타깃 / LC`를 구한다.
- **S (샘플 평균)**: LC가 다른 겔에 있으면(재프로빙, 별도 블롯) 같은 이름 샘플의 LC 평균으로 나눈다.
- **상대값** = 정규화 값 / 기준 샘플의 정규화 평균. 평균 ± SD, n = 레인 수로 표시한다.

## 4. 분석 파이프라인

```
원본 파일 ─decode─▶ 채널 ─gray─▶ 회전/뒤집기 ─▶ raw ─극성─▶ signal ─2D 배경─▶ signal'
                                                  │                              │
                                              포화 판정                    레인 프로파일
                                                                               │
                                                        베이스라인(16종) ─▶ 밴드 검출/수동 ─▶ 면적
```

| 단계 | 구현 | 위치 |
|---|---|---|
| 디코딩 | TIFF 8/16/32-bit·멀티페이지·WhiteIsZero·팔레트 (geotiff), PNG 16-bit·팔레트 (fast-png), JPG/BMP (브라우저) | `core/io/decode.ts` |
| 극성 | 어두운 밴드 반전 / 밝은 밴드 그대로 / OD = log₁₀(max/I). 열 중앙값을 뺀 잔차의 꼬리 비교로 자동 추천 | `core/image/preprocess.ts` |
| 2D 배경 | ImageJ BackgroundSubtracter 포팅: rolling ball(축소·arcTrim·bilinear 확대), sliding paraboloid, presmooth | `core/image/background2d.ts` |
| 레인 검출 | 행 하위 10% 제거 → 열 점수 → 슬라이딩 최솟값으로 비네팅 제거 → 로그 압축(진한/흐린 레인 평준화) → prominence 기반 봉우리 → 봉우리 사이 최솟값에서 경계, 반치폭으로 중심·폭. 레인이 붙어 있어도 골짜기만 보이면 나뉜다 | `core/lanes.ts` |
| 프로파일 | 레인 폭 방향 평균/중앙값, 가장자리 제외 %, 좌우 바깥 띠 중앙값(lane-edge용), 행별 포화 픽셀 수 | `core/profile.ts` |
| 베이스라인 | 16종 (아래 표) | `core/baseline/registry.ts` |
| 밴드 검출 | 가우시안 평활 → prominence 필터 → 경계 = 봉우리 대비 % 또는 골짜기 → 겹침은 최솟값에서 분할 | `core/bands.ts` |
| 밴드 기울기 | 밴드마다 기울기(px)를 두고, 그 값으로 다시 뽑은 프로파일·베이스라인에서 면적을 구한다. 이미지에서는 평행사변형으로 표시하고 양 끝 손잡이로 조절 | `core/profile.ts`, `engine/engine.ts` |
| 면적 | area = Σ(profile − baseline) (음수 0 처리 선택), volume = area × 사용 열 수, 높이, 위치, 포화 픽셀 | `core/bands.ts` |

### 베이스라인 16종

| 그룹 | 방법 | 핵심 파라미터 |
|---|---|---|
| 기본/수동 | 없음, 수동 포인트 (직선/PCHIP) | 점 좌표 |
| 기하학 | Valley-to-valley, 프로파일 최솟값, Lane edge | 끝점 평균 폭, 백분위수, 평활 σ |
| 형태학 | Rolling ball/disk (1D), Top-hat, Rubber band | 반경(% 레인 길이), 세로 스케일, 굽힘 |
| 평활 기반 | SNIP (차수 2–8, LLS), 이동 중앙값 + Gaussian | 창 절반(%) |
| Whittaker | AsLS, airPLS, arPLS, psalsa | log₁₀λ(1000점 기준 환산), p, k |
| 다항식 | ModPoly, IModPoly | 차수, 표준편차 배수 |

- **화면에 보이는 방법 (v0.3)**: 없음, 수동 포인트, Rolling ball, Top-hat, Rubber band, SNIP, 이동 중앙값. 나머지는 `VISIBLE_BASELINES`에서 빠져 있을 뿐 코드와 테스트에 남아 있고, 예전 프로젝트가 쓰던 방법이면 목록에 함께 표시된다.
- 창 크기는 **레인 길이 대비 %**로 지정하고, 화면에는 선택한 레인 기준 px 값도 함께 보여 준다. 이렇게 지정해 해상도가 다른 이미지에서도 같은 설정이 비슷하게 동작한다.
- Whittaker λ는 `λ_eff = 10^logλ · (n/1000)⁴`로 환산한다 (2차 차분의 스케일링).
- 적용 범위: **겔 기본값** 또는 **레인 개별**. "모든 겔에 이 설정 적용"으로 프로젝트 전체를 통일한다.
- **수동 (밴드 시작·끝점)**: 밴드마다 `(start, baseStart)`–`(end, baseEnd)`를 직선으로 이어 바닥선으로 쓴다. 높이를 정하지 않은 끝점은 그 위치의 프로파일 값(골짜기). 그래프의 동그라미를 끌면 가로는 밴드 경계, 세로는 바닥 높이가 바뀐다. 오른쪽 클릭으로 높이를 자동으로 되돌린다.
- "수동으로 다듬기": 현재 자동 바닥선이 각 밴드 양 끝에서 지나는 높이를 시작·끝점으로 옮겨 담고 그 레인을 수동으로 바꾼다. 곡선이던 바닥선이 직선이 되므로 면적이 조금 달라질 수 있다.
- 기울어진 밴드 구간은 그래프의 검은 프로파일·바닥선도 그 기울기로 다시 뽑은 값으로 그려, 화면과 적분값이 일치한다.
- 방법마다 요약 / 적합한 상황 / 주의 / 출처 설명 카드를 표시한다.

## 5. 표준곡선 (별도 탭)

- **입력**: 스프레드시트형 표. 엑셀에서 `양 · 신호` 두 열을 붙여넣으면 여러 행이 채워진다 (머리글 자동 건너뜀). 신호는 직접 입력하거나 **밴드와 연결**할 수 있다. 연결된 행은 베이스라인을 바꾸면 자동으로 갱신된다.
- **밴드에서 가져오기**: 겔과 타깃을 고르고 밴드를 체크한다. 샘플 이름의 숫자(예: "Std 10 ng")를 양으로 미리 채운다.
- **모델**: 선형, 원점 통과 선형, 2차, 거듭제곱(log–log), 로그, 4PL(Levenberg–Marquardt). 가중치는 없음 / 1/x / 1/x².
- **출력**: 식, R², 보정 R², RMSE, 범위, LOD(3.3σ/기울기)·LOQ(10σ/기울기). 표준 시료별 역산값·회수율, log x축 그래프.
- **역산**: 적용 타깃으로 지정된 밴드를 양으로 환산한다 (표준에 쓰인 밴드는 제외). 표준 범위 밖이면 "외삽"으로 경고한다. 결과 탭의 "정량값"으로도 요약할 수 있다.

## 8. 검증 (tests/core.test.ts)

| 테스트 | 기준 |
|---|---|
| Whittaker 밴드 솔버 | 밀집 행렬 방정식 잔차 1e-8 |
| 베이스라인 7종 (급한 기울기 + 곡선 배경) | 봉우리 3개 면적 오차 < 15% |
| Top-hat, 중앙값 (완만한 배경) | 면적 오차 < 15% (급한 기울기 한계는 설명 카드에 명시) |
| Lane edge (정답 가장자리) | 배경과 일치 |
| 2D rolling ball / paraboloid | 완만한 배경 제거, 작은 점 신호 보존 |
| 합성 겔 | 극성 추천 정확, 레인 5개 중심 ±6px, 면적–양 선형 R² > 0.99 |
| 16-bit TIFF | 크기·비트·값 보존, 레인 6개 검출 |
| 실제 겔 사진 (tests/fixtures/real-gel.png) | 사다리 + 시료 6개 = 레인 7개, 간격 편차 < 15%, 폭이 간격보다 작음 |
| 밴드 기울기 | 기울기를 따라가면 봉우리가 번지지 않고(높이 회복), 총 면적은 유지 |
| 밴드 생성 | id가 항상 부여됨 (자동 검출 밴드의 선택·표준곡선 연결이 깨지지 않도록) |
| 표준곡선 | 선형·거듭제곱·4PL·2차 역산 |
| 정규화 | 같은 레인 LC, 다른 겔 LC 평균, 기준 샘플 상대값 |

**데모 프로젝트로 확인한 정확도**: 겔 3장, p-ERK 표준 1–16 ng. 정답 상대값 1 / 1.44 / 2.93 / 3.77에 대해 측정값 1 / 1.45 / 2.96 / 3.84. 표준곡선 R² = 1.0000, 미지 시료 역산 2.99 (정답 3), 4.62 (정답 4.6).
